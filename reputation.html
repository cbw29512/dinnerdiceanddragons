WHAT COUNTS · WHAT DOESN'T

Experience, reputation, and moderation stay separate.

Self-reported experience

Years playing, years GMing, systems, editions, and formats. Useful context, clearly labeled as self-reported.

Verified reputation

Completed sessions, attendance, no-shows, description accuracy, repeat participation, and eligible would-repeat feedback.

Private moderation

Reports, allegations, evidence, warnings, restrictions, and investigations. These do not become public ratings automatically.

FAIR-START GUARANTEE

A first-time user should still be able to get a first table.

The ranking system must be audited for newcomer disadvantage. If new but eligible users receive materially fewer impressions or successful matches simply because they lack history, the ranking design is failing.

Hard rules

  • No history = neutral.
  • No missing metric is displayed as 0%.
  • New users lose no Table Fit points.
  • Reputation is not an ordinary eligibility requirement.
  • One negative interaction does not automatically trigger a public caution label.
  • Public aggregates require minimum sample sizes.
  • Safety restrictions are handled through moderation, not popularity ranking.

ROLE-SPECIFIC TRUST

Different roles should be judged on behavior that actually matters.

🎲 Player

  • Verified sessions attended
  • Attendance reliability
  • Late cancellations / no-shows
  • Repeat tables
  • Eligible table-respect feedback

🧙 Game Master

  • Verified games hosted
  • Completion reliability
  • Listing accuracy
  • Boundaries respected
  • Repeat Players
  • Would play again

🍽️ Venue

  • Verified sessions hosted
  • Table availability honored
  • Environment/accessibility accuracy
  • Venue cancellations
  • Would return

THE PRINCIPLE

Reputation reduces uncertainty. It does not decide who deserves to play.

Table Match gets people to the opportunity. Verified history helps them understand what has happened before.
